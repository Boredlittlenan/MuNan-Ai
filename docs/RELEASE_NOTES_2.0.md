# MuNan AI 2.0 更新说明

发布日期：2026-05-09

## 版本号

- 前端 `package.json`：`2.0.0`
- Rust crate `src-tauri/Cargo.toml`：`2.0.0`
- Tauri 打包配置 `src-tauri/tauri.conf.json`：`2.0.0`

## 主要更新

### AI HTML/CSS 卡片

- AI 回复支持 `<ai_card>` 结构化卡片，可用于天气、日程、价格对比、旅行计划、数据摘要等更适合视觉化展示的内容。
- 卡片包含简单版和完整版两种视图，用户可在 AI 回复操作区切换。
- 卡片使用 iframe `srcdoc` 沙箱渲染，不执行 JavaScript，不引入外部脚本或外部 CSS。
- 聊天气泡和卡片容器改为弹性宽高，减少固定尺寸造成的留白、嵌套卡片和横向滚动问题。

### 计划任务

- 设置页新增独立“计划任务”设置选项。
- 支持手动创建提醒、闹钟、日程提醒和 AI 定时执行任务。
- 调度方式直接支持单次、每日、每周、每月、每年和自定义天数。
- 单次任务填写完整日期时间；每日填写时间；每周支持多选星期和时间；每月选择 1-31 号和时间；每年选择月份、日期和时间；自定义天数填写间隔天数和时间。
- 任务字段包含名称、调度方式、执行时间、任务类型、执行模型和任务内容。
- 支持编辑、暂停、删除、重置任务。
- 聊天回复支持 `<scheduled_task>`，AI 可根据用户“明早提醒我看天气”等自然语言请求自动创建计划任务。
- 新增专用计划任务规划器：用户输入疑似计划任务时，应用会先让 AI 输出结构化任务草案，再由前端校验保存，避免普通回复只说“已创建”但没有真实落库。
- 聊天可修改、暂停/恢复或删除已有计划任务，例如“把天气提醒改到早上 8 点”“暂停喝水提醒”“取消明天的闹钟”。
- 单次聊天任务增加本地兜底解析，模型漏写 `<scheduled_task>` 时也会按本机当前时间创建真实任务。
- Rust 聊天命令会注入当前本地时间，帮助模型把“今天、明天、下周”等相对时间换算成明确日期。
- 应用打开时，全局计划任务运行器会定时检查到期任务，即使停留在设置页也会执行，并把执行结果写入对应模型的“计划任务”会话。
- 单次任务执行成功后标记完成；非单次调度执行成功后会自动计算并保存下一次执行时间。

### Agent 与工具调用体验

- Agent 设置继续负责工具开关、Tavily 参数、高风险确认和单次任务步数。
- 计划任务从 Agent 设置中拆出，成为独立设置分类，避免功能入口过深。
- AI 定时执行任务仍复用现有模型调用和工具拦截链路；如果任务执行时需要 Tavily 或 Shell，仍遵循当前 Agent 设置与确认策略。

### 文档与维护

- README 已更新 2.0 当前能力说明。
- `docs/ARCHITECTURE.md` 已补充 AI 卡片、计划任务和响应块说明。

## 数据与兼容

- 现有模型配置、会话历史、Token 用量统计继续沿用原有存储。
- 计划任务当前保存于前端 `localStorage.agentScheduledTasks`。
- 计划任务是应用内调度，应用需要处于打开状态才会检查和执行；当前版本尚未接入系统级后台任务或系统通知。

## 验证建议

```bash
pnpm build
cd src-tauri
cargo check
cargo fmt --check
```

手动验证建议：

- 设置页能看到独立“计划任务”选项。
- 手动新增任务后，任务列表可显示、编辑、暂停、删除和重置。
- 聊天中请求未来提醒时，AI 能创建计划任务而不是只给文字承诺；聊天中修改或取消任务时，本地计划任务列表会真实变化。
- 到点任务会写入对应模型的“计划任务”会话。
- AI 卡片在简单/完整视图切换时，气泡宽高随内容自然变化。
